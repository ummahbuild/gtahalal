# Development plan

**Current reality:** `main` contains the merged early Bayhaven interactive prototype and three founder decision cards (PRs #62 and #74), but clean build and browser QA remain unverified. [Feature Registry](FEATURES_AND_IDEAS_REGISTRY.md) and [Logic Contract](FEATURE_LOGIC_AND_STATE_CONTRACT.md) distinguish implemented source from the much larger drafted mission backlog. Do not mark roadmap tasks done until verified.


## Phase 0 — scaffold
- [ ] Boot all three JS apps and shared packages
- [ ] Install lockfile, strict TypeScript and working CI
- [ ] Add licensing decision, security reporting and content-review policy
- [ ] Add one original low-poly city block and third-person movement

## Phase 1 — playable vertical slice
- [ ] Interaction raycast, physics, NPC dialogue and quest state machine
- [ ] Optional private niyyah reflection, save/load, accessibility settings
- [ ] 10 source-reviewed missions, local QA, no personal data

## Phase 2 — city packs and minigames
- [ ] Modular city pack schema, streaming and asset budgets
- [ ] Arabic-learning, safe-road-cleanup and ethical market minigames
- [ ] Research Wudu Hero and Mosque Maze; confirm license before integration

## Phase 3 — cooperative play
- [ ] Authoritative multiplayer, invite-only sessions, moderation, load tests
- [ ] Cultural reviewers for Nairobi, Lagos, Addis Ababa and other cities

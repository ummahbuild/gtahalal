Secondary CTA: Read the vision (local page section)

## Sections
**Your choices shape the neighborhood.**
Help a neighbor, build community trust, and discover how ordinary decisions connect to larger stories. The first interactive neighborhood is an early development prototype.

**Build, don't destroy.**
From ethical food and fair finance to privacy-first technology and independent media, the planned campaign explores how communities can create alternatives to exploitative systems.

**A life beyond one character.**
Proposed stories include marriage, raising children, elder care, janazah, inheritance, and passing responsibilities to future generations. Sensitive paths are optional.

**Learn with care.**
Planned educational experiences cover Arabic, Qur'an study, purification, prayer and community service. Religious instruction remains draft until qualified review.

**An original world, city by city.**
Start with a fictional neighborhood, then expand through locally reviewed city packs, culturally grounded stories and licensed original 3D assets.

**Built in the open.**
Developers, artists, narrative designers, accessibility specialists and qualified Islamic reviewers can help shape Dunya through GitHub issues and pull requests.

## FAQs
**Can I play Dunya today?** Not as a verified public release. The repository has an early 3D prototype and a draft interactive slice under review.
**Is this a GTA mod?** No. Dunya is an original project with no Rockstar code or assets.
**Does Dunya issue religious rulings?** No. Educational content requires sourced scholarly review.
**Will it be on mobile?** Mobile-browser accessibility is a design goal, not a verified release promise.
**How do I contribute?** Visit the public GitHub repository and read its contributor guide.

## Copy guardrails
No fabricated gameplay footage, screenshots, user testimonials, partnerships, religious endorsements, performance metrics, launch dates, or app-store availability.

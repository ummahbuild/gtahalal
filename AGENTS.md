# Agent and contributor harness

Canonical organization repository: https://github.com/ummahbuild/gtahalal. Start at [requirements index](docs/REQUIREMENTS_INDEX.md), check current issues and open PRs before proposing duplicate work; historical PR #62 has been merged. Do not refer contributors to the former owner URL.

1. Read [Feature and Ideation Registry](docs/FEATURES_AND_IDEAS_REGISTRY.md) and [Feature Logic and State Contract](docs/FEATURE_LOGIC_AND_STATE_CONTRACT.md) before adding features; update both whenever ideation, behavior, state or requirements change.
2. Start with [one-URL agent onboarding](docs/AGENT_ONE_URL_START.md), run `python3 scripts/agent_bootstrap.py`, then read README and relevant app/package docs. Fix reproducibility blockers before claiming the project builds. Keep work scoped and testable.
2. This is a PUBLIC repository. Never commit secrets, personal identifiers, private correspondence, precise user locations, or proprietary assets.
3. No crime, violence, gambling, adult exploitation, hate, or harmful mission design. Do not copy GTA/Rockstar UI, names, art, sounds or code.
4. Qur'an/Hadith references are research leads until reviewed. Link to Quran.com/Sunnah.com and record review status; do not invent translations or religious guarantees.
5. Niyyah is private and optional; never gamify actual divine reward. Measure fictional community impact instead.
6. All art must have provenance and license records. Avoid real sacred building interiors without permissions.
7. For each PR: tests, accessibility, performance, privacy and security review; update docs and issue references.
8. Prefer TypeScript strict, small packages, deterministic quest logic, versioned schemas and accessible interfaces.
9. Run `pnpm lint && pnpm typecheck && pnpm test && pnpm build` when available; disclose commands not run.
10. No direct production deployment or merge without checks and review.
